# Luci flix
Site pessoal que lista meus filmes e séries preferidos (tema rosa e preto).

## Como rodar
Basta abrir o `index.html` (duplo clique ou Live Server). Mantenha todos os arquivos na mesma pasta.

## Como adicionar/editar filmes
Edite `filmes.js`: título, descrição, duração, gênero, classificação, `imagem` (arquivo dentro de `Imagens/`) e `trailer` (só o ID do vídeo do YouTube).
